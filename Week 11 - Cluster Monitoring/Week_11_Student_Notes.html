1. Rationale: The Storage I/O Bottleneck

While Network File System (NFS) provides simple centralized storage over corporate LANs, it suffers from severe single-server I/O bottlenecks when thousands of compute ranks attempt concurrent reads/writes. Supercomputers require Parallel File Systems (PFS) built on enterprise mass storage hardware.

2. Mass Storage Technologies (Chapter 17)

Storage TechnologyHardware MechanismPerformance Profile
Hard Disk Drives (HDD)Magnetic platters & mechanical read heads.High capacity, lower cost per TB, good sequential throughput, poor random IOPS.
Solid State Drives (SSD)NAND Flash memory cells.Zero seek latency, high random IOPS (~100K+ IOPS).
NVMe-oF (Fabrics)PCIe NVMe over InfiniBand/RoCE.Ultra-low latency sub-10 microsecond RDMA direct memory access.

3. Architecture of Parallel File Systems (Chapter 18)

Parallel file systems decouple Metadata Operations (file permissions, directory trees) from Raw Data Chunk Transfers:

ComponentLustre TerminologyOperational Function
Metadata ServerMDS / MDTManages filenames, directory structures, ACL permissions, and file striping maps.
Object Storage ServerOSS / OSTStores actual file data chunks across striped high-speed disk arrays.
Client DriverLustre ClientProvides POSIX interface to Linux apps while streaming data blocks directly to/from OSTs in parallel.

4. File Striping Mechanics

Files are divided into fixed-size chunks (e.g., 1 MB) and written across multiple OST storage targets simultaneously:

Terminal 
# Set Lustre striping count=4 targets, size=1MB on a shared directory
lfs setstripe -c 4 -S 1M /mnt/lustre/scratch/dataset

# Query file striping layout
lfs getstripe /mnt/lustre/scratch/dataset/simulation_data.bin

5. Parallel I/O Interfaces: MPI-IO

Standard C POSIX write() serializes file operations. **MPI-IO** allows thousands of ranks to write to a single file concurrently:

Terminal 
#include <mpi.h>

MPI_File fh;
MPI_Offset offset = rank * sizeof(double) * 1000;

// Open shared parallel file across communicator
MPI_File_open(MPI_COMM_WORLD, "simulation_output.dat", 
               MPI_MODE_CREATE | MPI_MODE_WRONLY, MPI_INFO_NULL, &fh);

// Write local array chunk at designated file offset in parallel
MPI_File_write_at_all(fh, offset, local_buffer, 1000, MPI_DOUBLE, MPI_STATUS_IGNORE);

MPI_File_close(&fh);
