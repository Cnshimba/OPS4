Week 3 Slides: Node Provisioning (Warewulf 4)

Slide 1: The Provisioning Challenge

  • The Problem: How to install the OS on 500 nodes?
  • Manual Install: CD/USB? Impossible at scale.
  • Imaging: Cloning disks? Slow and stateful.
  • The Solution: Network Provisioning (PXE).

Slide 2: Stateless Clustering

  • Stateless: No OS on the hard drive.
  • Process:
    1. Node powers on (Network Boot).
    2. Pulls OS Image from Master into RAM.
    3. Runs completely in Memory.
  • Advantages:
    • Speed: RAM is faster than Disk.
    • Consistency: Every reboot resets to "Golden State".
    • Scale: Update one file on Master -> Update 1000 nodes.

Slide 3: Introduction to Warewulf 4

  • What is it?: The open-source standard for HPC provisioning.
  • Architecture Change:
    • Old (WW3): Custom "VNFS" images. Complex.
    • New (WW4): OCI Containers.
  • Concept: Your Compute Node OS is just a Docker Container.

Slide 4: Anatomy of a Warewulf Boot

  1. DHCP: Master gives Node an IP.
  2. iPXE: Node downloads the advanced bootloader.
  3. HTTP: Node pulls the Container Image (Compressed).
  4. Overlays: Master injects specific files (e.g., /etc/hostname) to customize the node.
  5. Kernel: Linux boots.

Slide 5: The Warewulf Object Model

  • Node: A physical machine (MAC Address, IP).
  • Profile: A template for grouping nodes (gpu-nodes, web-servers).
  • Inheritance:
    1. Default Profile: Global settings.
    2. Specific Profile: Group settings.
    3. Node: Specific overrides.
  • Power: Define settings once (in Profile), apply to many.

Slide 6: The Warewulf Tools

  • wwctl: The single command wrapper.
    • wwctl container import: Fetch a Docker image.
    • wwctl profile set: Configure a group template.
    • wwctl node add: Register a new physical server.
    • wwctl configure: Build the services (DHCP/TFTP).

Slide 7: Lab Overview

  • Goal: Build a functional Provisioning Server.
  • Steps:
    1. Install Warewulf 4 on Master.
    2. Import rockylinux:9 container from the internet.
    3. Configure the default Profile.
    4. Register node01 (MAC Address required!).
    5. Boot node01 via Network.
