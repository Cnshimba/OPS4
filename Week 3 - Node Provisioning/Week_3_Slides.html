Week 3 Presentation Deck: Node Provisioning Strategies

Vagrant Virtualization Mechanics, Warewulf 4 OCI Bare-Metal Protocols & Decision Engineering

Slide 1: What is Node Provisioning?

  • Definition: The automated pipeline allocating hardware, instantiating operating systems, and configuring network interfaces for cluster nodes.
  • Scale Bottleneck: Manual USB installation of 500 servers consumes >250 hours of work.
  • Bit-for-Bit Consistency: Guarantees every compute node runs identical libraries, preventing floating-point simulation drift.

Slide 2: Vagrant & Virtualization Mechanics (Lab 1)

  • Vagrant Box Packaging: Tarball archive containing virtual disk (`.vmdk`), metadata JSON, and provider configuration. Uses Copy-on-Write linked clones for sub-60-second multi-VM boot.
  • Virtual Network Drivers:
    • NAT (eth0): Outbound internet access and SSH port forwarding (`127.0.0.1:2222` -> `:22`).
    • Host-Only Private Network (eth1): Isolated virtual switch (`vboxnet0`) for static IP cluster communication (`192.168.56.0/24`).
  • Pipeline: State Check -> Linked Clone -> Hardware Tuning -> Network Binding -> SSH Communicator -> Shell Provisioner.

Slide 3: Warewulf 4 Bare-Metal Architecture & Boot Stack

  • OCI Container Revolution: Replaces legacy Perl/VNFS tarballs with Go-based OCI containers (built via standard Dockerfiles).
  • 5-Stage Boot Protocols:
    1. IPMI: Hardware power-on via out-of-band BMC (`wwctl power on`).
    2. DHCP (`dnsmasq`): MAC to IP binding & `ipxe.efi` bootloader path.
    3. TFTP: Stage-1 iPXE transfer to RAM.
    4. HTTP: Multi-gigabit transfer of kernel (`vmlinuz`) & OS container (`rootfs.img`).
    5. Overlays: Ingesting System (initramfs) & Runtime (`wwclient`) overlays.

Slide 4: Provisioning Strategy Selection Matrix

  • Vagrant + VirtualBox: Best for local R&D, lab work, CI testing. Zero hardware cost; limited by laptop RAM (3-8% hypervisor loss).
  • Warewulf 4 (Stateless Bare-Metal): Best for production supercomputers & physical clusters. 100% bare-metal speed; zero disk latency; immutable golden image resilience.
  • Stateful Disk Imaging: Best for static computer labs. High disk I/O maintenance; severe configuration drift over time.
