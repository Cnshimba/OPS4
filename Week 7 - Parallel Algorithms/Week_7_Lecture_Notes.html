Week 7: Parallel Algorithms - Lecture Notes

Topic: Decomposition Strategies and Load Balancing. Reference: Sterling Chapter 9.

1. The Strategy of Parallelism

  • Writing code (MPI/OpenMP) is just the implementation.
  • The real challenge is Algorithm Design: How do we split the problem?

2. Decomposition Strategies

  • Domain Decomposition (Data Splitting):
    • Divide the grid/matrix/physical space into chunks.
    • Assign each chunk to a rank.
    • Ghost Cells (Halo Regions): Boundary layers used to exchange data with neighbors.
    • Communication: Halo exchange step (MPI_Isend / MPI_Irecv).
    • Example: Heat Equation, Fluid Dynamics.
  • Functional Decomposition (Task Splitting):
    • Divide the work into distinct functions.
    • Rank 0-10: Physics; Rank 11-20: Chemistry.
    • Pipeline Pattern: Input -> Process -> Output.
    • Example: Climate Models (Ocean vs Atmosphere).

3. Load Balancing

  • The Problem:
    • Workload is rarely uniform (e.g., storms in weather model).
    • Load Imbalance: Fast nodes wait for slow nodes (Idle time = Wasted resources).
  • The Solution:
    • Static Load Balancing: Pre-assign work carefully (hard to predict).
    • Dynamic Load Balancing: Shift work at runtime.
    • Master-Worker Pattern: Master hands out small chunks; Workers ask for more when done.
