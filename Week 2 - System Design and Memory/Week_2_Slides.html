Week 2 Presentation Deck: System Design & Memory Architecture

NUMA, Cache Coherence & Beowulf Cluster Topology

Slide 1: The Beowulf Revolution

  • The Problem: Supercomputers were expensive and proprietary (Cray/IBM).
  • The Solution: Beowulf Clusters (1994, NASA).
    • Build a supercomputer from cheap, mass-market parts (COTS).
    • Connect PCs with Ethernet.
    • Run Linux.
  • Result: 90% of Top500 systems today are Linux Clusters.

Slide 2: Cluster Anatomy

  • Master Node: The Gateway. Users login here. Runs Scheduler & Provisioning.
  • Compute Nodes: The Workers. Headless, Diskless.
  • Interconnect: The Nervous System. High-speed network (InfiniBand/Ethernet).
  • Storage Node: Centralized Data (NFS/Lustre).

Slide 3: Network Topologies

  • Goal: Connect 1,000 nodes without bottlenecks.
  • Fat Tree:
    • Hierarchical.
    • Branches get "thicker" (more bandwidth) near the root.
    • Pro: Non-blocking (Full speed for everyone).
    • Con: Expensive (Lots of switches).
  • Torus (3D):
    • GridMesh. Nodes connect to neighbors (N/S/E/W/U/D).
    • Pro: Cheap (Fewer switches). Good for physics.

Slide 4: Critical Services (The Lab)

To make a node boot without a disk, we need:

  1. DHCP: Assigns an IP address to the node.
  2. TFTP: Sends the tiny Bootloader (ipxe.efi).
  3. HTTP: Sends the large OS Image (Linux Kernel + RootFS).

Slide 5: Lab Overview

  • Goal: Build the networking foundation manually.
  • Tool: dnsmasq (DHCP + TFTP server).
  • Steps:
    1. Install dnsmasq.
    2. Configure IP ranges.
    3. Open Firewall (Ports 67/69).
    4. Verify with nmap broadcast.
