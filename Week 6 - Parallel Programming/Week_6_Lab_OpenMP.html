📋 Overview

Distributed-memory High-Performance Computing relies on the Message Passing Interface (MPI) standard to enable communication across isolated compute nodes. This lab covers installing Open MPI, configuring the environment with Lmod, verifying PMIx-Slurm integration, and writing parallel programs in both C and Python.

2.2 Create the C MPI Program

Create /shared/mpi_hello.c:

Terminal
Terminal Command 
#include <mpi.h>
#include <stdio.h>
#include <unistd.h>

int main(int argc, char **argv) {
    int rank, size;
    char hostname[256];
    MPI_Init(&argc, &argv);
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);
    gethostname(hostname, sizeof(hostname));
    printf("Hello from rank %d of %d running on %s\n", rank, size, hostname);
    MPI_Finalize();
    return 0;
}

Section 4: Hybrid MPI + OpenMP Parallel Implementation

In modern high-performance clusters, computing nodes feature multi-core CPUs. A hybrid parallel programming model combines MPI (for inter-node distributed-memory communication) with OpenMP (for intra-node shared-memory multithreading across CPU cores on each node).

4.1 Create the Hybrid C Program

Create /shared/mpi_omp_hybrid.c:

Terminal
Terminal Command 
#include <mpi.h>
#include <omp.h>
#include <stdio.h>
#include <unistd.h>

int main(int argc, char **argv) {
    int rank, size;
    char hostname[256];
    int provided;

    // Initialize MPI with thread support level
    MPI_Init_thread(&argc, &argv, MPI_THREAD_FUNNELED, &provided);
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);
    gethostname(hostname, sizeof(hostname));

    #pragma omp parallel
    {
        int tid = omp_get_thread_num();
        int nthreads = omp_get_num_threads();
        printf("MPI Rank %d of %d (Host: %s) -> OpenMP Thread %d of %d\n",
               rank, size, hostname, tid, nthreads);
    }

    MPI_Finalize();
    return 0;
}

4.2 Compile and Submit via Slurm

Terminal
Terminal Command 
module load mpi/openmpi-x86_64
mpicc -fopenmp /shared/mpi_omp_hybrid.c -o /shared/mpi_omp_hybrid
export OMP_NUM_THREADS=2
srun -N 2 -n 2 --cpus-per-task=2 /shared/mpi_omp_hybrid

Expected output:

Terminal
Terminal Command

MPI Rank 0 of 2 (Host: compute01) -> OpenMP Thread 1 of 2
MPI Rank 1 of 2 (Host: compute02) -> OpenMP Thread 0 of 2
MPI Rank 1 of 2 (Host: compute02) -> OpenMP Thread 1 of 2

Section 6: Troubleshooting

⚠ mpirun / mpicc Not Found

Symptom: Executing compiler wrappers yields 'command not found'.
Solution: Run module load mpi/openmpi-x86_64. For direct diagnostics, append /usr/lib64/openmpi/bin to PATH.

⚠ mpi4py Cannot Load MPI Library

Symptom: RuntimeError: cannot load MPI library. libmpi.so: cannot open shared object file.
Solution: Ensure Lmod is loaded: source /etc/profile.d/modules.sh; module load mpi/openmpi-x86_64. Or manually export: export LD_LIBRARY_PATH=/usr/lib64/openmpi/lib:$LD_LIBRARY_PATH

⚠ MPI/PMIx Connection Failures

Symptom: mpi/pmix_v3: _tcp_connect: Cannot establish connection.
Cause: Firewalld is blocking inter-node traffic.
Solution:
pdsh -R ssh -g compute "sudo firewall-cmd --permanent --add-rich-rule='rule family=\"ipv4\" source address=\"192.168.56.0/24\" accept' && sudo firewall-cmd --reload"
