HPC Synthesis, Scientific Stack & Live Algorithm Demonstration
Slide 1 Curriculum Synthesis & Scope

Capstone Project: The Grand Synthesis

  • Team Structure: Students collaborate in pairs (groups of 2).
  • Curriculum Focus: Exclusively covers competencies from:
    • Lab 1 & Lab 2: Multi-node virtualization, network topology, Chrony, NFS, Munge & Slurm.
    • Lab 3: Open MPI 4.1.x, PMIx scheduler integration, and wrapper compilers.
    • Lab 4: Building the Scientific Software Stack from source & Lmod environment modules.
    • Lab 6: HPC Cluster Benchmarking with High-Performance Linpack (HPL).
    • Chapter 8 Workbook: Distributed-Memory Parallel Programming with MPI.
  • Evaluation Format: Live demonstration per group to the lecturer including an On-The-Fly Algorithm Challenge and individual oral defense.
Slide 2 Infrastructure Foundation

Starting Baseline (Provided to Students)

  • Pre-Configured Infrastructure: The lecturer provides a working 5-node Rocky Linux 9.6 cluster.
  • Topology: 1 Controller (master: 4GB RAM, 2 CPUs) + 4 Compute Workers (compute01-04: 2GB RAM, 2 CPUs each).
  • Active Services:
    • Chrony time synchronization (server master iburst).
    • Private subnet 192.168.56.0/24 with complete /etc/hosts mapping.
    • NFS exported /shared directory mounted across all nodes.
    • Munge cryptographic key authentication active and authorized.
    • Slurm Workload Manager active: slurmctld on master, slurmd on workers in healthy IDLE state.
    • Open MPI 4.1.x runtime and mpicc compiler wrappers integrated with Slurm.
Slide 3 Milestone 1 — Scientific Software

Compiling the Scientific Stack (Lab 4)

  • All packages compiled from source under /shared/apps/ and propagated cluster-wide:
  • OpenBLAS: Optimized BLAS/LAPACK compiled with DYNAMIC_ARCH=1 USE_OPENMP=1.
  • FFTW 3: Fast Fourier Transforms configured with --enable-shared --enable-mpi.
  • Parallel HDF5: Hierarchical parallel I/O compiled using CC=mpicc --enable-parallel.
  • ScaLAPACK: Distributed dense linear algebra built using CMake linked explicitly to custom OpenBLAS.
  • PETSc: Portable PDE solver toolkit linking OpenBLAS, ScaLAPACK, Parallel HDF5, and Open MPI.
Slide 4 Milestone 2 — Lmod & Python

Lmod Modules & Centralized mpi4python (Lab 4)

  • Lmod Lua Modulefiles:
    • Located in /shared/modulefiles/<library>/<version>.lua.
    • Prepends binary paths, dynamic linkers (LD_LIBRARY_PATH), and header search trees.
    • Tested via module use /shared/modulefiles && module avail.
  • Centralized Python HPC Environment:
    • Deployed under /shared/apps/python-hpc-env.
    • site.cfg directs pip to compile NumPy bound to your custom OpenBLAS.
    • mpi4python (mpi4py) compiled and configured to enable distributed Python across cluster nodes.
    • Controlled via unified Lmod module python-hpc/1.0.lua.
Slide 5 Milestone 3 — Benchmarking

High-Performance Linpack Benchmarking (Lab 6)

  • HPL Compilation: Compile xhpl linking custom OpenBLAS and Open MPI.
  • HPL.dat Parameter Tuning:
    • Problem Size (N): Tuned to occupy ~80% of aggregate compute RAM (e.g., N ≈ 25,000) to prevent disk swap.
    • Block Size (NB): Cache-aligned block cyclic distribution (NB = 128).
    • Process Grid (P × Q): Configured as P=2, Q=4 matching 8 Slurm tasks (4 nodes × 2 tasks/node).
  • Metrics Evaluation:
    • Theoretical Peak: Rpeak = 4 × 2 × 2.4 × 4 = 76.8 GFLOPS.
    • Sustained Peak (Rmax) parsed from HPL output table.
    • Cluster Efficiency: E = (Rmax / Rpeak) × 100%.
Slide 6 Milestone 4 — MPI Programming

Distributed MPI Programming (Chapter 8)

  • Point-to-Point: MPI_Send() and MPI_Recv() with ranks, tags, and status.
  • Synchronization: MPI_Barrier() and host querying (MPI_Get_processor_name()).
  • Collectives:
    • MPI_Bcast(): Root broadcasts scalar/array to all active ranks.
    • MPI_Scatter(): Partitions global array on root into equal segments per rank.
    • MPI_Gather(): Gathers local results from all ranks back into an array on root.
    • MPI_Allgather(): Gathers local data and delivers the complete dataset to all ranks.
  • Reductions: MPI_Reduce() using reduction operators (MPI_SUM, MPI_MIN, MPI_MAX).
  • Synthesized Pipeline: Multi-stage distributed weather data analysis and Monte Carlo Pi estimation.
Slide 7 Strict 30-Min Live Demo

Live Assessment: 30-Minute Laptop Demonstration

  • Demonstration Setting: Student pairs demonstrate their cluster live on their own laptops (all 5 VMs pre-booted and idle).
  • Randomized Spot-Check Protocol:
    • The assessor randomly selects 1 C benchmark and 1 Python script from /shared/cluster_test_suite/.
    • The suite covers all 6 compiled scientific stack components:
      • OpenBLAS matrix calculation (cblas_dgemm)
      • FFTW 3 parallel 2D Fourier transform
      • Parallel HDF5 distributed collective hyperslab I/O
      • ScaLAPACK distributed matrix multiply (pdgemm)
      • PETSc distributed Poisson sparse solver (KSP)
      • Core MPI / mpi4py Monte Carlo Pi reduction
  • TOP500 Linpack Verification: Execute python3 python/top500_report_generator.py to produce and verify the official cluster certificate live!
Slide 8 Evaluation Rubric

Grading Rubric & Oral Defense (100 Marks)

  • 1. Slide Presentation (20 Marks · 8 mins): Max 6 slides presented equally by the pair (4 mins each). Clear architectural & parameter explanation.
  • 2. Cluster Health & Infrastructure (20 Marks · 6 mins): All 4 compute nodes IDLE, NFS mounts active, /shared/verify_capstone.sh audit achieves 100% PASS.
  • 3. Functional Library Validation (30 Marks · 7 mins): Live execution of randomly selected C test (15 marks) and Python test (15 marks) without memory faults.
  • 4. TOP500 Linpack Performance (20 Marks · 4 mins): Residual check PASSED (< 16.0), measured $R_{max}$ GFLOPS verified, Efficiency $E \ge 65\%$.
  • 5. Operational Agility & Teamwork (10 Marks · 5 mins): Quick terminal navigation, clean exit codes, agile coordination, and oral defense answers.
