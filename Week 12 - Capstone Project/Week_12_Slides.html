Week 12 Slides: The Capstone Project

Slide 1: The Journey

  • Weeks 1-2: Design & Hardware (Architecture).
  • Weeks 3-4: Provisioning (Warewulf) & Scheduling (Slurm).
  • Weeks 5-7: Compute (OpenMP, MPI, Benchmarking).
  • Weeks 8: Storage (NFS, BeeGFS, I/O Benchmarking).
  • Week 9: Accelerators (GPU).
  • Week 10: Applications (CFD, Bio).
  • Week 11: Monitoring (Prometheus, Grafana).
  • Week 12: Integration.

Slide 2: The Final Challenge

  • Goal: Demonstrate a functional Mini-Cluster.
  • Requirement: All systems must talk to each other.
    • Network -> Provisioning -> Scheduler -> Storage -> App -> Monitor.
  • The Pass Condition:
    • A successful OpenFOAM run script handled by Slurm.

Slide 3: Troubleshooting Strategy

  • Layer 1: Physical (Virtual)
    • Are the nodes on? Can you ping them?
  • Layer 2: Provisioning
    • Did they boot the correct image? (wwctl node list)
  • Layer 3: Middleware
    • Is Slurm happy? (sinfo)
    • Is BeeGFS mounted? (df -h)
  • Layer 4: Application
    • Did you load the module?

Slide 4: Grading Rubric

  • Infrastructure (25%): wwctl shows nodes fully provisioned.
  • Monitoring (25%): Grafana Dashboard showing live cluster data.
  • Programming (50%):
    • Successful sbatch submission.
    • Parallel Code (Matrix Mult/Sort) executes correctly.
    • Execution time scales/reports correctly.

Slide 5: Good Luck!

  • This course was not about memorizing commands.
  • It was about understanding how massive systems are built from small pieces.
  • Welcome to the world of HPC.
