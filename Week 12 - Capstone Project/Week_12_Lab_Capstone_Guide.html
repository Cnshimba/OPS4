1. Executive Summary & Project Goal

The Capstone Project synthesizes all theoretical and practical competencies acquired across the 12-week course into a single production-grade automated deployment. Students are required to design, script, and provision a fully functioning 5-node Rocky Linux 9.6 HPC Cluster (1 Controller Master Node + 4 Compute Worker Nodes) using Infrastructure as Code (IaC) principles.

2. Core Architectural Components

Your automated deployment scripts (bootstrap_master.sh and bootstrap_compute.sh) must configure five integrated subsystems:

1. Infrastructure & Network (IaC)

Vagrantfile automation deploying master (4GB RAM, 2 CPUs) and compute01-04 (2GB RAM each) on private subnet 192.168.57.0/24 with Chrony time sync.

2. Storage & Security

Multi-host private NFS export (/shared/apps, /shared/modulefiles), ED25519 passwordless SSH, and Munge cryptographic authentication.

3. Slurm Workload Scheduler

Multi-node Slurm orchestrator (slurmctld on master, slurmd on worker nodes) managing job queues and hardware allocations.

4. Scientific Software Stack

Lmod Environment Modules, source-compiled OpenBLAS (with OpenMP), FFTW 3 (with MPI), Parallel HDF5, ScaLAPACK, and Python mpi4py.

3. Master & Worker Provisioning Scripts

3.1 Master Node Provisioning Script (bootstrap_master.sh)

The master node script configures core network routes, installs system services, compiles scientific libraries from source, and starts monitoring daemons:

bootstrap_master.sh — Master Node Script
Terminal Command 
#!/usr/bin/env bash
set -euo pipefail

echo ">>> [STAGE 1] Configuring Hostnames & Network..."
hostnamectl set-hostname master

cat << 'EOF' > /etc/hosts
127.0.0.1   localhost
192.168.57.10 master
192.168.57.11 compute01
192.168.57.12 compute02
192.168.57.13 compute03
192.168.57.14 compute04
EOF

echo ">>> [STAGE 2] Installing Core Packages..."
dnf install -y epel-release
dnf install -y vim nano wget curl git chrony tar unzip rsync pdsh pdsh-rcmd-ssh \
               nfs-utils slurm slurm-slurmctld slurm-slurmd munge munge-libs Lmod

echo ">>> [STAGE 3] Provisioning NFS Shared Storage..."
mkdir -p /shared/apps /shared/modulefiles
chmod 777 /shared
echo "/shared 192.168.57.0/24(rw,sync,no_root_squash)" > /etc/exports
systemctl enable --now nfs-server exportfs -rav

echo ">>> [STAGE 4] Munge Cryptographic Key Generation..."
dd if=/dev/urandom bs=1 count=1024 of=/etc/munge/munge.key
chown munge:munge /etc/munge/munge.key
chmod 400 /etc/munge/munge.key
systemctl enable --now munge
cp /etc/munge/munge.key /shared/munge.key

echo ">>> [STAGE 5] Slurm Scheduler & Monitoring Services..."
systemctl enable --now slurmctld prometheus node_exporter grafana-server

4. Capstone Project Deliverables & Evaluation Criteria

Students must submit their full Git repository containing:

  • Automated Vagrantfile defining the 5-node topology.
  • bootstrap_master.sh and bootstrap_compute.sh shell scripts.
  • Validation Verification Log proving sinfo, srun -N4 hostname, and Lmod module load openblas fftw3 hdf5 execute cleanly across all nodes.
