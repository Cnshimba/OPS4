Week 1 Slides: HPC Introduction & Architectures

Slide 1: Introduction

  • Module: Operating Systems 4 (High Performance Computing)
  • Topic: Infrastructure and Architecture
  • Goal: Understanding the "Why" and "How" of Supercomputing.

Slide 2: What is HPC?

  • Definition: Aggregating computing power to solve problems too large for a single machine.
  • Throughput vs Speedup:
    • Standard Server: Many small tasks (Web requests).
    • HPC Cluster: One massive task (Weather model).
  • Metrics:
    • FLOPS: Floating Point Operations Per Second.
    • Top500: Ranked list of world's fastest systems (Benchmark: HPL).

Slide 3: The Physics of Computing

  • Von Neumann Architecture:
    • Shared Code/Data memory.
    • Bottleneck: CPU waits for data.
  • The Memory Wall:
    • CPUs got faster (Moore's Law).
    • RAM didn't keep up.
    • Latency: The time to wait for data (RAM = Slow).

Slide 4: Hiding Latency (Architectural Solutions)

  • Caches (SRAM):
    • L1/L2/L3 Caches keep frequent data close to the CPU.
    • Spatial Locality: Use arrays contiguous in memory.
    • Temporal Locality: Reuse variables quickly.

Slide 5: Parallelism at the Core

  • Pipelining:
    • Analogy: Car Assembly Line.
    • Execute 1 instruction per cycle by overlapping stages.
  • SIMD (Vectorization):
    • Single Instruction, Multiple Data.
    • Process 4, 8, or 16 numbers with ONE command.
    • Critical for performance (AVX-512).

Slide 6: Part 1 Goal - The Cluster

  • Next week, we move up the stack:
    • From Processor Architecture (Micro).
    • To System Architecture (Macro).
  • We will build a Beowulf Cluster:
    • Commodity Hardware + Private Network + Linux + Middleware.

Slide 7: Lab - Networking Refresher

  • Prerequisites for Clustering:
    1. Identity: Everything needs a name (/etc/hosts).
    2. Access: Automated control (SSH Keys).
    3. Communication: TCP/IP Basics.
  • Task: Setup Master/Node SSH trust.
